# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |

Only the latest Aether Launcher release line is supported. Stock ZalithLauncher2 issues
belong upstream, not here.

## Reporting a vulnerability

**Do not open a public issue for security reports.** Instead, open an issue titled
`[SECURITY]` with minimal details and the maintainer will follow up — or ping GrayDev
through the contact listed on the GitHub profile.

Please include:

- App version and device/Android version
- What you expected vs. what happened
- Steps to reproduce (without exploit payloads in public)

Aim: acknowledge within a few days, fix and release as soon as practical. There is no
bug-bounty program; credit is given in release notes with the reporter's consent.
